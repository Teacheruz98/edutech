# EduTech Pro - Termiz Presidential School Platform

## 1. Purpose
Digitalize school processes, specifically the grading system and internal communication. Focus on teacher ease-of-use, student transparency, and a secure environment.

## 2. Key Features
- **Secure Access & Admin Control:** Registration required with admin approval (`isApproved: true`).
- **Teacher Module:** Student list, Summative grade entry for Visual Arts, editing, and database saving.
- **Student Module:** Personal grade table with subject filtering.
- **AI & Notifications:** AI-generated greetings and an important announcements/news feed.
- **Multilingual Support:** Interface in Uzbek, Russian, and English.

## 3. Design Concept (Google Stitch / Material Design)
- **Clean UI:** Ample white space, minimalist.
- **Cards:** Used for student data and grades.
- **Typography:** Roboto or Product Sans.
- **Colors:** White, Gray, Primary Blue (Google Blue). Vibrant Google-style accents (Green, Red, Yellow) for buttons.
- **Navigation:** Compact sidebar or Navbar.

## 4. User Flow
1. **Registration:** User submits details.
2. **Waiting Room:** "Wait for admin approval" message.
3. **Login:** Redirect to Teacher or Student panel post-approval.
4. **Actions:** Teacher sets grade -> DB updates -> Student views result.

## 5. Design Prompt Context
- Modern dashboard look.
- Data tables with cards.
- Rounded corners (12px-16px).
- AI daily announcements section.
- Responsive design for Phone, Tablet, Laptop, and Full Screen.
